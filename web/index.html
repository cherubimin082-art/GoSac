This console shows build and connection status only — it has no backend, so it can't run an agent's code itself. Most platforms show "Auto-detected" status: Mariner's connection_status.py checks each agent's config.yaml for real (non-placeholder) credentials and this page reads that file — no manual click needed, and no live API call happens just from loading this page. Re-run that script after filling in real credentials to refresh it. A platform without that signal (like Beacon's Looker Studio connector, set up manually in its own UI) still uses the "Mark connected" toggle, which stays on this device only. Scheduling and execution are handled by Mariner, run from a terminal or a scheduled job — see its README for how.
