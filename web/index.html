This console is a multi-client platform: each client in the sidebar has their own set of agent configs and connection status, kept fully separate. "+ Add client" works only in the local console (python web/server.py), since adding a client scaffolds real config folders on disk and this published page has no backend to do that.

This console shows build and connection status only — it has no backend of its own for running agent code unless the local console is up. Most platforms show "Auto-detected" status: Mariner's connection_status.py checks each client's config.yaml for real (non-placeholder) credentials, and this page reads that result — no manual click needed, and no live API call happens just from loading this page. A platform without that signal (like Beacon's Looker Studio connector, set up manually in its own UI) still uses the "Mark connected" toggle, which stays on this device only. Scheduling and execution are handled by Mariner — see its README for how.
